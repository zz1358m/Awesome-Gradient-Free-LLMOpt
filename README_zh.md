## ES 与 ZO 的使用方式不同

ES 和双点 ZO 都可以看作平滑目标函数的估计方法，但现有大语言模型文献通常将二者用于明显不同的场景。

| | 进化策略（ES） | 零阶优化（ZO） |
|---|---|---|
| 主要目标 | 直接任务奖励：`max E[R(model rollout)]` | 监督损失：`min CE/NLL(model(x), y)` |
| 评估单元 | 一组受扰动模型，每个模型分别生成新的 rollout | 通常在 `theta + eps*z` 和 `theta - eps*z` 上进行一次或少量成对前向评估 |
| 反馈信号 | 精确匹配/验证器得分、环境回报、偏好或对齐奖励 | token 级 CE/NLL、困惑度或其他相对平滑的损失 |
| 本列表中的主要用途 | 推理后训练和长时程智能体 | 内存高效的监督微调与参数高效适配 |
| 代表性数据集 | Countdown、GSM8K、MATH 类评测、Sudoku、ARC-AGI、PRM800K、IFEval；智能体场景还包括 WebArena-Lite | SST-2、RTE、BoolQ、WiC、CB、COPA、SNLI/MNLI/QNLI、SQuAD、DROP 和常识问答 |

这种区分很重要：终局推理奖励通常是稀疏、离散且随机的，因为每次扰动都会生成新的 rollout。种群评估、适应度归一化或排序以及奖励加权的 ES 更新正是为这类场景设计的。成对双点 ZO 则在两个函数值高度相关时最有效，例如在同一 minibatch 上计算确定性的监督微调损失。

这里描述的是主流实践中的分类，而不是数学上的硬性限制。ES 也可以最小化监督损失；当基于奖励的 ZO 使用大量扰动时，其形式也会逐渐接近 ES。

## 收录范围

视觉语言动作模型通过零阶方法更新持久动作侧参数的适配研究可收录，并须注明语言骨干是否冻结。ES/ZO 主分类要求持久模型或适配器更新；关联分类保留如实标注的混合、闭式、推理时、非提示词外部工件和已确认智能体模型/控制器训练研究。

每个边界条目分别说明各组件是否反向传播、是否持久更新模型权重、是否持久保存外部工件，以及尚待核实的事实。“evolving”一词本身不能证明采用了进化算法。缺少具体优化机制的泛智能体演化研究和没有 LLM/VLM 关联的论文仍不收录。

自 2026-10-12 起，现行目录临时排除以技能生成、技能库、技能检索、技能优化/自演化、技能与 policy 共演化、技能组合或技能基函数适配为主要对象或核心机制的论文。该决定是用户要求的暂缓收录，不是学术否定，也不是 `skill` 关键词黑名单。[37 条逐篇审查](data/literature_reviews/2026-10-12-skill-scope-audit.md)与[可恢复原始记录](data/deferred_papers/2026-10-12-skills.json)保留完整证据；只有用户明确解除限制后才能恢复。

同日起，以提示词、软提示、模板或 context-space 适配为核心的论文暂缓收录。智能体型机制仅在原始来源确认持久更新 LLM、策略模型、适配器、神经控制器或等价模型参数时保留。规则按真实机制而非文章标签判断：冻结 LLM 依据反馈反复优化程序、算法、算子、workflow、知识、记忆、检索状态、搜索树或候选解，即使被称为程序优化、自动设计、黑箱优化或 controller，也属于暂缓范围。合成代码中的数值参数本身不能证明模型训练；参数类型不明者进入可恢复的“参数训练证据待核实”组。一次性先验编译、普通参数训练仅把 prompt 作为输入、模型内部分析、非智能体合并/压缩、受害模型攻击或测量不自动排除。参见[范围收紧报告](data/literature_reviews/2026-10-12-prompt-agent-scope.md)、[389 条完整决定](data/literature_reviews/2026-10-12-prompt-agent-scope-decisions.json)与[可恢复记录](data/deferred_papers/2026-10-12-prompt-agent-scope.json)。
